# 开发任务规划

## 1. 编号规则

- `S0`：阶段 0，工程与文档基线；
- `S1`：阶段 1，内部数据采集测试版基础；
- `S2`：阶段 2，高速传感器采集与真机验证。

完成状态必须区分“代码完成”“模拟器验证”和“真机验证”。

## 2. 阶段 0

| 编号 | 任务 | 当前状态 | 验收 |
|---|---|---|---|
| S0-001 | 初始化 Git 与忽略规则 | 已完成 | `main` 仓库可用，不跟踪构建和研发数据 |
| S0-002 | 建立 iPhone 研发 target | 代码完成 | 模拟器构建通过；真机待验证 |
| S0-003 | 建立 Apple Watch 研发 target | 代码完成 | 模拟器构建通过；真机待验证 |
| S0-004 | 建立共享核心模块 | 已完成 | 双端引用同一数据模型，单元测试通过 |
| S0-005 | 数据定义与架构初稿 | 已完成 | 文档与代码字段一致 |
| S0-006 | 基础测试环境 | 已完成 | Swift Package 测试和双端构建可重复执行 |
| S0-007 | 真机最小应用验证 | 待开始 | iPhone 与目标 Apple Watch 安装运行 |

## 5. 下一项建议任务

下一项应同时推进 `S0-007` 与 `S1-002/S1-003`：

1. 确认内部研发 Bundle Identifier 和 Apple Developer Team；
2. 在真实 iPhone 和最低目标 Apple Watch 上安装当前最小应用；
3. 实现测试者资料与采集会话状态机；
4. 再接入 Core Motion 真机适配器；
5. 不在此阶段加入击球检测、杀球分类或测速。
