# 开发任务规划

## 1. 编号规则

- `S0`：阶段 0，工程与文档基线；
- `S1`：阶段 1，内部数据采集测试版基础；
- `S2`：阶段 2，高速传感器采集与真机验证。

完成状态必须区分“代码完成”“模拟器验证”和“真机验证”。

## 2. 阶段 0

| 编号 | 任务 | 当前状态 | 验收 |
|---|---|---|---|
| S0-001 | 初始化 Git 与忽略规则 | 已完成 | `main` 仓库可用，不跟踪构建和研发数据 |
| S0-002 | 建立 iPhone 研发 target | Simulator 完成 | 构建、安装、启动通过；真机待验证 |
| S0-003 | 建立 Apple Watch 研发 target | Simulator 完成 | 构建、安装、启动通过；真机待验证 |
| S0-004 | 建立共享核心模块 | 已完成 | 双端引用同一数据模型，单元测试通过 |
| S0-005 | 数据定义与架构初稿 | 已完成 | 文档与代码字段一致 |
| S0-006 | 基础测试环境 | 已完成 | `Scripts/verify.sh` 可重复运行核心测试和双端构建 |
| S0-007 | 真机最小应用验证 | 按用户要求暂缓 | iPhone 与目标 Apple Watch 安装运行 |

## 3. 阶段 1

| 编号 | 任务 | 当前状态 | 主要输出 |
|---|---|---|---|
| S1-001 | 研发采集模式入口 | Simulator 完成 | 单次、普通批量、杀球批量、自由、干扰入口与标签约束 |
| S1-002 | 测试者资料管理 | Simulator 完成 | 资料创建、本地保存、稳定 UUID、版本化分级代码 |
| S1-003 | 采集会话状态机 | Simulator 完成 | 准备、采集中、停止、中断、完成、失败 |
| S1-004 | 手表本地采集存储 | Simulator 完成 | 分批追加、清单检查点、完成状态、启动恢复 |
| S1-005 | 待同步队列 | 核心协议完成 | 离线保留、待传输状态、幂等入站；平台发送与确认待实现 |
| S1-006 | 手机接收与列表 | Simulator 完成 | 完整性确认、样本计数、去重、冲突拒绝、研发采集列表 |

阶段 1 Simulator 范围于 2026-08-12 关闭。真机离线、后台运行和 WatchConnectivity 仍必须在相应阶段补验。

## 4. 阶段 2

| 编号 | 任务 | 当前状态 | 主要输出 |
|---|---|---|---|
| S2-001 | Core Motion 真机适配器 | 代码完成，真机待验 | 三轴数据、姿态、独立时间戳、SI 单位和能力检测 |
| S2-002 | 缓冲、检查点与异常恢复 | 核心完成，真机待验 | 高频数据分批落盘和中断保护 |
| S2-003 | 采样质量统计 | 代码完成，阈值待研究 | 分来源间隔和有界缓冲溢出计数；丢样与疑似饱和需真机结论 |
| S2-004 | 手机原始曲线 | 代码完成，交互补验 | 加速度、角速度和实际间隔曲线；有界抽样不替代完整导出 |
| S2-005 | 研发数据导出 | 自动测试完成 | 版本化 header、测试者/采集元数据和完整原始样本 NDJSON |
| S2-006 | 第一轮真机实验 | 待开始 | 普通、杀球、空挥、干扰和自由打球数据 |
| S2-007 | 数据质量结论 | 待开始 | 书面结论和是否进入下一阶段的门禁决定 |

## 5. 下一项建议任务

下一项应推进 `S2-001/S2-003/S2-004/S2-005`：

1. 实现 Core Motion 真机适配器和能力检测，Simulator 继续使用显式合成源；
2. 补齐独立数据流间隔、异常间隔和可配置质量统计；
3. 实现手机原始曲线与研发数据导出；
4. 准备签名与真实设备后执行 S0-007 和第一轮真机实验；
5. 在真机数据质量书面结论形成前，不加入击球检测、杀球分类或测速。
