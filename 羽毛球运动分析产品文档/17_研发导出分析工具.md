# 研发导出分析工具

## 1. 目的与边界

- 工具：`Scripts/analyze_research_exports.py`
- 报告格式版本：1
- 运行时依赖：Python 3.7 或更高，仅使用标准库
- 输入：单个、多个 `.badminton-ndjson` 文件，或包含该文件的目录

该工具只进行流式结构校验与客观摘要。它不识别击球、不分类杀球、不估算速度，也不自动判定真机数据质量门禁是否通过。

## 2. 使用

分析单个文件：

```sh
python3 Scripts/analyze_research_exports.py path/to/capture.badminton-ndjson
```

分析整个批量导出目录并保存报告：

```sh
python3 Scripts/analyze_research_exports.py path/to/batch --output reports/batch.json
```

生成可归档的 Markdown 实验摘要：

```sh
python3 Scripts/analyze_research_exports.py path/to/batch \
  --format markdown \
  --output reports/batch.md
```

Markdown 报告包含整体汇总、单次采集与分传感器流摘要、错误与警告，并固定标注“质量门禁未评估”。

输入存在结构错误时进程返回 2；全部文件通过基础结构校验时返回 0。

## 3. 每个采集的输出

报告保留：

- 采集 UUID、schema、模式、人工标签、数据来源和复核状态；
- 清单声明样本数与实际样本数；
- 加速度计、陀螺仪和设备运动各自的记录数；
- 每个数据流的首尾单调时间戳；
- `actualIntervalSeconds` 和原始时间戳差分别计算的数量、最小值、平均值和最大值；
- 非单调时间戳、序号倒退、通道负载缺失、样本数不符等结构错误；
- 清单中已记录的异常间隔、疑似丢样和疑似饱和警告；
- 外部真实测速的值、来源、配对标识与真机单次杀球约束；
- 真机数据导出时测试者资料缺失警告。

整个分析逐行读取，不会把整场高频样本同时载入内存。

## 4. 不可误读的字段

- `structural_integrity = true` 只表示文件和基础时序没有被工具发现结构错误；
- `provenance_eligible` 只表示来源为 `physical_sensor`；
- `review_eligible` 只表示人工复核为 `valid`；
- `quality_gate_decision` 在当前工具中始终为 `not_evaluated`。

即使前三项均没有问题，仍需要根据真机实验协议人工检查饱和、丢样、长时间运行、电量与数据是否支持后续研究，才能形成书面门禁结论。

## 5. 自动测试

`Scripts/tests/test_analyze_research_exports.py` 覆盖：

- 正常三记录导出的分数据流摘要；
- 声明样本数不符与时间戳倒退；
- 目录输入展开和批量汇总；
- 报告始终不伪造质量门禁决定。

`Scripts/verify.sh` 会在 Swift 测试和双端构建前自动运行这些 Python 测试。
