# 第一版功能范围

## 1. 目的

本文件同时锁定：

- 正式第一版的功能边界
- 正式产品开发前必须完成的内部研发阶段

编码代理不得自行跨越阶段门禁。

## 2. 正式产品开发前必须完成：内部数据采集测试版

内部数据采集测试版是强制研发交付物，不属于正式用户功能。

### 2.1 手表端必须支持

- 单次击球采集
- 普通击球批量标注采集
- 杀球批量标注采集
- 自由连续采集
- 空挥和其他干扰动作采集
- 原始三轴加速度
- 原始三轴角速度
- 可获得的姿态与设备运动数据
- 独立时间戳
- 采样间隔记录
- 异常采样记录
- 有效或无效标记
- 手机不在附近时本地保存

### 2.2 手机端研发工具必须支持

- 接收手表研发数据
- 测试者资料管理
- 按日期、模式和标签查看采集记录
- 查看原始运动曲线
- 查看采样间隔和异常情况
- 标记有效、无效、待检查
- 录入可选外部真实杀球速度
- 导出完整研发数据

### 2.3 研发采集原则

- 普通击球和杀球标签由用户事先指定
- 未验证模型不得覆盖人工标签
- 自由连续采集默认没有逐拍真实标签
- 真实速度字段默认为空
- 不得用估算结果填写真实速度字段

### 2.4 研发阶段门禁

数据采集测试版未完成真机验证前：

- 不进入正式杀球识别发布逻辑
- 不进入正式杀球测速发布逻辑
- 不生成用户可见的伪速度
- 不使用固定系数冒充最终算法

## 3. 正式第一版必须实现

### 3.1 首次设置

- 身高
- 臂展
- 羽毛球水平
- 持拍手佩戴提示
- 必要健康与运动权限
- 是否进行个人动作校准

不要求填写左右持拍手。

### 3.2 个人动作校准

- 可以跳过
- 普通击球十个有效样本
- 杀球十个有效样本
- 必须真实击球
- 无效样本补打
- 保存个人动作基线
- 可以重新校准

### 3.3 苹果手表运动记录

- 开始
- 暂停
- 继续
- 结束
- 手机不在附近时正常工作
- 异常中断数据保护
- 健康数据
- 手腕运动数据
- 本地缓存

### 3.4 基础运动健康数据

至少包括：

- 开始时间
- 结束时间
- 运动时长
- 当前心率
- 平均心率
- 最高心率
- 心率区间数据
- 活动消耗热量
- 总消耗热量

步数可以记录，但不是第一版核心展示指标。

### 3.5 真实击球检测

- 从连续运动数据发现疑似挥拍
- 确认是否真实击球
- 过滤空挥、捡球、跑动、甩手、擦汗等
- 只有确认真实击球才增加总击球数

### 3.6 击球分类

用户侧只允许：

- 杀球
- 普通击球

系统内部可以存在非击球状态。

### 3.7 杀球测速

- 只有杀球进入测速流程
- 满足可信条件才生成用户可见速度
- 单位为公里每小时
- 显示到小数点后一位
- 低可信杀球仍可计数
- 低可信杀球不参与平均、最快和个人纪录

### 3.8 杀球震动

- 每识别到一次杀球轻微震动一次
- 不按速度改变震动强度
- 不全屏打断

### 3.9 手表运动界面

第一页：

- 运动时间
- 当前心率
- 活动消耗热量
- 总击球数

第二页：

- 本场杀球数
- 最近一次成功速度
- 本场最快速度

### 3.10 手机端报告

- 历史运动
- 单场报告
- 全部击球明细
- 历史个人最快杀球

单场主要指标：

- 运动时间
- 总击球数
- 杀球数
- 最快杀球速度
- 活动消耗热量

### 3.11 击球明细

每次有效击球保存独立记录。

手机端查看：

- 击球时间
- 普通击球或杀球
- 杀球是否有有效速度
- 有效速度值

手表端不显示完整列表。

### 3.12 苹果健康与健身体系

运动结束后应正常进入苹果健康与健身记录体系。

### 3.13 手机与手表同步

- 手机不在附近时手表独立记录
- 重新连接后自动同步
- 同步失败重试
- 防止重复运动
- 成功确认后再清理手表临时数据

## 4. 正式第一版可预留但不展示

- 更细球路分类
- 击球质量
- 甜区位置
- 挥拍强度
- 球拍参数
- 更复杂个人模型
- 用户主动纠错
- 更复杂个人模型训练

## 5. 正式第一版明确不做

- 网球
- 比分
- 回合
- 对手数据
- 胜率
- 训练建议
- 疲劳分析
- 语音播报
- 摄像头
- 球拍数据库
- 球拍切换
- 云端账号
- 云端存储
- 社交
- 排行榜
- 自动重算历史数据

## 6. 暂缓由技术验证决定

- 原始传感器数据长期保留策略
- 杀球识别可信阈值
- 测速可信阈值
- 实际采样频率
- 单次击球窗口长度
- 最低手机系统版本
- 最低手表系统版本
- 电池消耗目标
